# فاحص أندرويد لويندوز

واجهة عربية باستخدام Python وTkinter وAndroid Debug Bridge. المشروع مستقل عن موقع adawatak-site.

## التشغيل على Windows 10/11

1. ثبّت Python 3.12 من python.org مع Tcl/Tk.
2. نزّل **SDK Platform Tools for Windows** من https://developer.android.com/tools/releases/platform-tools وفك مجلد `platform-tools` بجوار `app.py`، أو أضف مساره إلى PATH. لا تنزّل ADB من مصادر مجهولة.
3. ثبّت تعريف USB الرسمي للشركة المصنعة إذا لزم، وفعّل خيارات المطور ثم USB debugging. وصّل كابل بيانات وافتح الهاتف ووافق على بصمة الكمبيوتر.
4. من مجلد المشروع شغّل `python app.py`، ثم «تحديث الأجهزة»، واختر الجهاز ثم «بدء الفحص».

لا يحتاج البرنامج إلى صلاحيات root أو مفاتيح API. لا يوجد تثبيت حزم Python لتشغيله من المصدر.

## الإمكانيات والحدود

- قراءة طراز الهاتف وإصدار Android والتصحيح الأمني والبطارية والحرارة والذاكرة والتخزين وعينة استخدام المعالج.
- تحذيرات عند حرارة ≥45° أو تخزين ≥90% أو ذاكرة متاحة <10% أو حالة بطارية غير جيدة وفق النظام. القراءات الناقصة تسجل كأخطاء، وليست دليلاً على سلامة الجهاز.
- نسبة الشحن ليست نسبة السعة المتبقية أو صحة البطارية. لا يقيس البرنامج دورات الشحن أو السعة الفعلية ولا ينفذ benchmark أو يكشف كل أعطال العتاد والبرامج.
- زر التحديث يفتح صفحة تحديث النظام الرسمية؛ لا يدعي وجود تحديث متاح ولا يثبت firmware.
- زر إعادة الضبط يطلب تحذيرًا ثم يفتح صفحة الهاتف. المستخدم يؤكد المسح على الهاتف. لا يرسل البرنامج أمر wipe ولا يتجاوز قفل الشاشة أو FRP. بعض الشركات لا تدعم اختصارات الإعدادات؛ افتح الصفحة يدويًا حينها.
- تقرير JSON يحتوي معرف الجهاز وبيانات التشخيص، احفظه محليًا وراجعه قبل مشاركته. لا يرسل البرنامج التقرير إلى خادم.

## إنشاء EXE على ويندوز

```powershell
python -m pip install pyinstaller==6.16.0
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --onedir --windowed --name AndroidPhoneCheck app.py
```

النتيجة `dist/AndroidPhoneCheck/AndroidPhoneCheck.exe`. ضع `platform-tools` داخل `dist/AndroidPhoneCheck/_internal/` أو أضف ADB إلى PATH. شارك مجلد `AndroidPhoneCheck` كاملاً، وليس EXE وحده. الملف غير موقّع رقميًا. عند رفع هذا المشروع كمستودع مستقل، يمكن تشغيل workflow المرفق لبناء نسخة Windows وتنزيلها كـ artifact؛ لا ينشرها تلقائيًا.

## التحقق

`python -m unittest discover -s tests -v` يفحص تحليل القراءات والتحذيرات والفشل الجزئي بمحاكاة ADB. يلزم اختبار واقعي على ويندوز وهاتف أندرويد مصرح به للتحقق من الاتصال والواجهة واختصارات إعدادات الشركة المصنعة. لا يتم تنفيذ مسح بيانات في الاختبارات.
